#### Esta aplicación surgió como una respuesta a los inconvenientes con proyectos grandes que realizamos. Surgió de una necesidad personal de tener claridad a la hora de organizar desarrollos en tareas más pequeñas que sean llevaderas. Nuestro objetivo es evitar la sobrecarga de información, el burnout y la procrastinación que surge al sentirnos abrumados por la exigencia de tareas grandes.
